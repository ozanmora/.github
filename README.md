# .github

Default community health files for repositories owned by [@ozanmora](https://github.com/ozanmora).

- [`.github/FUNDING.yml`](.github/FUNDING.yml) adds a **Sponsor** button to every repository that does not have its own
  funding file and has *Sponsorships* enabled in its settings.
